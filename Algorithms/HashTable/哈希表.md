## 1. 理论基础

### 1.1 什么是哈希表

哈希表（Hash Table）是根据关键码（Key）的值直接进行访问的数据结构。它通过哈希函数将键映射到数组下标，从而实现 **O(1) 平均时间** 的增删改查。

```
key  →  哈希函数  →  数组下标  →  直接访问

  "apple"  →  hash("apple")=5  →  table[5]
```

**核心价值**：一般哈希表都是用来**快速判断一个元素是否出现在集合里**。

### 1.2 哈希函数

哈希函数将键（key）通过 `hashCode` 转换为数组索引：

```
index = hashCode(key) % tableSize
```

- 理想哈希函数：分布均匀、计算快速、冲突少
- 当 `hashCode` 大于哈希表大小，取模映射到合法范围
- 当键的数量远大于表大小，必然产生**哈希碰撞**

### 1.3 哈希碰撞及解决方法

哈希碰撞：不同的输入经过哈希函数得到相同的输出值。

| 方法 | 原理 | 优点 | 缺点 |
|------|------|------|------|
| **链地址法**（拉链法） | 碰撞元素用链表串联 | 实现简单，负载因子可超 1 | 链表过长时退化为 O(n) |
| **开放地址法**（线性探测） | 冲突时探测下一个空位 | 缓存友好，无需额外指针 | 聚集问题，删除复杂 |
| **再哈希法** | 用第二个哈希函数重新计算 | 减少聚集 | 计算开销大 |

Python 的 `dict` 和 `set` 采用**开放地址法**（具体的 perturbed hash probe），平均 O(1) 访问。

### 1.4 负载因子

```
负载因子 = 元素个数 / 哈希表大小
```

- 负载因子过高 → 冲突增多 → 性能下降
- 负载因子过低 → 空间浪费
- Python `dict` 在负载因子超过 2/3 时自动扩容（rehash）

## 2. 何时使用哈希表

### 2.1 识别信号

遇到以下需求时，**第一时间想到哈希法**：

| 信号 | 典型场景 | 对应题目 |
|------|----------|----------|
| **快速判断元素是否在集合里** | 查重、查存在 | 两数之和、快乐数 |
| **统计元素出现频率** | 频率对比、计数 | 字母异位词、赎金信 |
| **记录已访问的状态** | 环检测、去重 | 快乐数、数组交集 |
| **需要 key→value 映射** | 下标记录、分组求和 | 两数之和、四数相加II |

### 2.2 何时不用哈希表

| 场景 | 更优选择 | 原因 |
|------|----------|------|
| 需要**有序**遍历 | 排序数组 / 树 | 哈希表无序 |
| 需要**去重且有序**的三元组/四元组 | 排序 + 双指针 | 哈希表去重逻辑复杂 |
| 数据范围小且连续（如 26 个字母） | 数组计数 | 数组更快更省空间 |
| 需要**前 K 大** | 堆 / 快速选择 | 哈希表无序 |

> **重要**：三数之和（LC 15）和四数之和（LC 18）虽然属于"求和"类，但**排序 + 双指针**优于哈希法，因为去重更自然、空间 O(1)。

## 3. Python 哈希相关数据结构

### 3.1 数据结构对比

| 结构 | 特点 | 典型用途 |
|------|------|----------|
| `dict` | 键值映射，键可哈希，3.7+ 有序 | 记录值→下标、分组计数 |
| `set` | 唯一元素集合，无序 | 去重、判断存在 |
| `frozenset` | 不可变集合，可哈希 | 作为字典的键 |
| `collections.defaultdict` | 带默认值的字典 | 避免键不存在判断 |
| `collections.Counter` | 计数字典 | 频率统计 |
| `collections.OrderedDict` | 有序字典（3.7 前） | LRU 缓存 |

### 3.2 选择指南

```
需要记录值→位置映射？            → dict
需要去重 / 判断元素是否存在？      → set
需要统计频率？                   → Counter 或 数组[26]
需要分组计数？                   → defaultdict 或 dict.get
```

### 3.3 常用技巧

```python
# 字典 get 方法避免 KeyError
count = dict.get(key, 0) + 1

# Counter 的运算（交集、并集、差集）
from collections import Counter
c1 & c2   # 交集：取较小计数
c1 | c2   # 并集：取较大计数
c1 - c2   # 差集：计数 > 0 的保留

# Counter 转列表（按计数展开）
list(counter.elements())

# 集合运算
set1 & set2   # 交集
set1 | set2   # 并集
set1 - set2   # 差集
```

### 4.2 频率统计类

**核心思想**：统计字符/元素出现次数，比较频率是否一致。

| 题目 | 数据范围 | 推荐结构 | 复杂度 |
|------|----------|----------|--------|
| 字母异位词（仅小写字母） | 26 | 数组 `[0]*26` | O(n) / O(1) |
| 赎金信（仅小写字母） | 26 | 数组 `[0]*26` | O(n) / O(1) |
| 任意 Unicode 字符 | 不定 | `Counter` / `dict` | O(n) / O(k) |

**关键判断**：数据范围小且连续 → 用数组；否则用 Counter。

### 4.3 集合查询类

**核心思想**：用集合存储一个数组的元素，遍历另一个数组判断是否存在。

| 题目 | 是否去重 | 推荐方法 |
|------|----------|----------|
| 交集（LC 349） | 去重 | `set & set` |
| 交集II（LC 350） | 不去重 | `Counter & Counter` |

### 4.4 状态记录类

**核心思想**：用哈希集合记录已访问的状态，检测重复（环）。

- **快乐数**：记录每次平方和，若重复出现则进入循环 → 不是快乐数
- 也可用**快慢指针**替代，空间 O(1)

### 4.5 哈希映射类（查补数）

**核心思想**：遍历时，用哈希表记录已遍历的值，查询 `target - 当前值` 是否在表中。

| 题目 | 分组 | 思路 |
|------|------|------|
| 两数之和 | 无 | 一遍哈希，查 `target - num` |
| 四数相加II | AB / CD 两组 | 枚举 AB 的和存表，枚举 CD 查 `-sum` |

**分组技巧**（四数相加 II）：
```
A[i] + B[j] + C[k] + D[l] == 0
→ A[i] + B[j] == -(C[k] + D[l])
→ 枚举 AB（O(n²)）存入哈希表，枚举 CD（O(n²)）查询
→ 总时间 O(n²)，空间 O(n²)
```

### 4.6 求和类（排序 + 双指针）

**注意**：三数之和、四数之和**不推荐用哈希表**，因为：
1. 去重逻辑复杂（需额外的集合）
2. 空间 O(n)
3. 排序 + 双指针去重更自然，空间 O(1)

| 题目 | 复杂度 | 去重方式 |
|------|--------|----------|
| 三数之和 | O(n²) | 跳过重复的 i, left, right |
| 四数之和 | O(n³) | 两层固定 + 跳过重复 + 剪枝 |

## 5. 解题模板

### 5.1 数组计数模板（适用 26 字母频率统计）

```python
def count_frequency(s: str) -> list[int]:
    """统计字符串中每个小写字母的出现频率"""
    counts = [0] * 26
    for ch in s:
        counts[ord(ch) - ord("a")] += 1
    return counts

# 字母异位词：两个字符串频率相同
# 赎金信：ransomNote 的频率 <= magazine 的频率
```

### 5.2 一遍哈希模板（查补数）

```python
def two_sum_hash(nums: list[int], target: int) -> list[int]:
    """一遍哈希：遍历时查补数"""
    seen: dict[int, int] = {}          # 值 → 下标
    for i, num in enumerate(nums):
        complement = target - num
        if complement in seen:          # 补数已出现
            return [seen[complement], i]
        seen[num] = i                   # 当前值存入表
    return []
```

### 5.3 分组哈希模板（四数相加 II）

```python
def four_sum_count(nums1, nums2, nums3, nums4) -> int:
    """分组 + 哈希表"""
    sum_count: dict[int, int] = {}
    # 枚举 AB 的和
    for a in nums1:
        for b in nums2:
            s = a + b
            sum_count[s] = sum_count.get(s, 0) + 1
    # 枚举 CD 查 -sum
    answer = 0
    for c in nums3:
        for d in nums4:
            answer += sum_count.get(-(c + d), 0)
    return answer
```

### 5.4 集合去重模板（数组交集）

```python
def intersection(nums1: list[int], nums2: list[int]) -> list[int]:
    """去重交集"""
    return list(set(nums1) & set(nums2))

def intersect(nums1: list[int], nums2: list[int]) -> list[int]:
    """不去重交集（保留重复）"""
    from collections import Counter
    common = Counter(nums1) & Counter(nums2)
    return list(common.elements())
```

### 5.5 状态记录模板（快乐数 / 环检测）

```python
def is_happy_hash(n: int) -> bool:
    """哈希集合记录状态，检测环"""
    def digit_square_sum(num: int) -> int:
        return sum(int(d) ** 2 for d in str(num))

    seen: set[int] = set()
    while n != 1 and n not in seen:
        seen.add(n)
        n = digit_square_sum(n)
    return n == 1
```

### 5.6 排序 + 双指针模板（三数之和）

```python
def three_sum(nums: list[int]) -> list[list[int]]:
    """排序 + 双指针 + 去重"""
    nums.sort()
    result = []
    n = len(nums)
    for i in range(n - 2):
        if nums[i] > 0:                          # 剪枝
            break
        if i > 0 and nums[i] == nums[i - 1]:     # 外层去重
            continue
        left, right = i + 1, n - 1
        while left < right:
            total = nums[i] + nums[left] + nums[right]
            if total < 0:
                left += 1
            elif total > 0:
                right -= 1
            else:
                result.append([nums[i], nums[left], nums[right]])
                while left < right and nums[left] == nums[left + 1]:    # 内层去重
                    left += 1
                while left < right and nums[right] == nums[right - 1]:  # 内层去重
                    right -= 1
                left += 1
                right -= 1
    return result
```

## 7. 扩展题型（目录未涉及）

### 7.1 最长连续序列（LC 128）

**题意**：给定未排序数组，找出最长连续元素序列的长度。要求 O(n)。

**思路**：用哈希集合存储所有数，对每个序列起点（`num - 1` 不在集合中）向后计数。

```python
def longestConsecutive(nums: list[int]) -> int:
    num_set = set(nums)
    max_len = 0
    for num in num_set:
        if num - 1 not in num_set:          # 只从序列起点开始计数
            current = num
            streak = 1
            while current + 1 in num_set:
                current += 1
                streak += 1
            max_len = max(max_len, streak)
    return max_len
```

**时间**：O(n)（每个元素最多被访问 2 次）；**空间**：O(n)

### 7.3 同构字符串（LC 205）

**题意**：判断字符串 s 和 t 是否同构（字符一一映射）。

**思路**：双向映射，确保 s→t 和 t→s 都是单射。

```python
def isIsomorphic(s: str, t: str) -> bool:
    s2t: dict[str, str] = {}
    t2s: dict[str, str] = {}
    for cs, ct in zip(s, t):
        if s2t.get(cs, ct) != ct or t2s.get(ct, cs) != cs:
            return False
        s2t[cs] = ct
        t2s[ct] = cs
    return True
```

### 7.4 字符串中第一个唯一字符（LC 387）

**题意**：找到字符串中第一个只出现一次的字符的下标。

```python
def firstUniqChar(s: str) -> int:
    counts = [0] * 26
    for ch in s:
        counts[ord(ch) - ord("a")] += 1
    for i, ch in enumerate(s):
        if counts[ord(ch) - ord("a")] == 1:
            return i
    return -1
```

### 7.5 单词规律（LC 290）

**题意**：判断字符串 pattern 和字符串 s 是否遵循相同规律。

```python
def wordPattern(pattern: str, s: str) -> bool:
    words = s.split()
    if len(pattern) != len(words):
        return False
    p2w: dict[str, str] = {}
    w2p: dict[str, str] = {}
    for p, w in zip(pattern, words):
        if p2w.get(p, w) != w or w2p.get(w, p) != p:
            return False
        p2w[p] = w
        w2p[w] = p
    return True
```

### 7.6 LRU 缓存（LC 146）

**题意**：实现 O(1) 的 get 和 put 操作的 LRU 缓存。

**思路**：哈希表 + 双向链表。哈希表存 key→节点，链表维护访问顺序。

```python
from collections import OrderedDict

class LRUCache:
    def __init__(self, capacity: int):
        self.cache = OrderedDict()
        self.capacity = capacity

    def get(self, key: int) -> int:
        if key not in self.cache:
            return -1
        self.cache.move_to_end(key)         # 移到末尾表示最近使用
        return self.cache[key]

    def put(self, key: int, value: int) -> None:
        if key in self.cache:
            self.cache.move_to_end(key)
        self.cache[key] = value
        if len(self.cache) > self.capacity:
            self.cache.popitem(last=False)  # 移除头部（最久未使用）
```

## 8. 易错点总结

### 8.1 数组 vs Counter 的选择

```
错误：数据范围小（如 26 个字母）时用 Counter
正确：用数组 [0]*26，更快更省空间

错误：数据范围大（如 Unicode）时用数组
正确：用 Counter / dict
```

### 8.2 两数之和的索引顺序

```python
# ✗ 错误：先存再查，可能用到自己
seen[num] = i
if complement in seen:
    return [seen[complement], i]

# ✓ 正确：先查再存
if complement in seen:
    return [seen[complement], i]
seen[num] = i
```

### 8.3 交集的去重与不去重

```
LC 349（去重）：set & set           → [1, 2]
LC 350（不去重）：Counter & Counter  → [1, 1, 2]
```

混淆两个题目会导致结果错误。

### 8.4 三数之和的去重位置

```python
# ✗ 错误：找到答案后才去重 i（导致重复记录）
for i in range(n):
    ...
    if total == 0:
        result.append(...)

# ✓ 正确：i 在循环开头就去重
for i in range(n):
    if i > 0 and nums[i] == nums[i - 1]:
        continue
```

### 8.5 四数之和的整数溢出

```python
# ✗ 错误：Python 不会溢出，但其他语言需要注意
# nums[a] + nums[b] + nums[c] + nums[d] 可能溢出 int32

# ✓ 正确：用排序后的和直接比较，或用 long
```

> Python 无整数溢出问题，但在 C++/Java 中需注意。

### 8.6 快乐数的终止条件

```python
# ✗ 错误：只检查 n == 1，可能死循环
while n != 1:
    n = digit_square_sum(n)

# ✓ 正确：同时检查是否进入循环（n 重复出现）
while n != 1 and n not in seen:
    seen.add(n)
    n = digit_square_sum(n)
```

### 8.7 哈希表 vs 排序 + 双指针

```
求两数之和（不需去重）          → 哈希表 O(n)
求三/四数之和（需去重且返回值）  → 排序 + 双指针（去重更自然）
求四数相加 II（四个独立数组）    → 分组 + 哈希表（不需去重，返回计数）
```

### 8.8 Counter 的 & 运算

```python
from collections import Counter
c1 = Counter([1, 1, 2, 3])
c2 = Counter([1, 1, 1, 2])

c1 & c2  # Counter({1: 2, 2: 1})  → 取较小计数
list((c1 & c2).elements())  # [1, 1, 2]
```

`&` 取的是**每个元素的最小计数**，用于不去重的交集。

## 9. 哈希表 vs 其他数据结构

### 9.1 复杂度对比

| 操作 | 哈希表 | 排序数组 | 二叉搜索树 | 平衡树 |
|------|--------|----------|------------|--------|
| 查找 | O(1)* | O(log n) | O(h) | O(log n) |
| 插入 | O(1)* | O(n) | O(h) | O(log n) |
| 删除 | O(1)* | O(n) | O(h) | O(log n) |
| 有序遍历 | O(n)** | O(n) | O(n) | O(n) |
| 前驱/后继 | O(n) | O(log n) | O(h) | O(log n) |

`*` 平均复杂度，最坏 O(n)；`**` 需额外排序；`h` 为树高。

### 9.2 选择决策树

```
需要有序遍历 / 范围查询？
├── 是 → 需要顺序
│   ├── 数据静态  → 排序数组 + 二分
│   └── 数据动态  → 平衡树（Python 无内置，用 sortedcontainers）
└── 否
    ├── 只需查找/去重/计数 → 哈希表（dict / set / Counter）
    └── 需要前 K 大/小      → 堆（heapq）
```

### 9.3 本目录题目的数据结构选择

| 题目 | 为什么选哈希表 | 为什么不选其他 |
|------|---------------|---------------|
| 字母异位词 | O(1) 查频率 | 排序 O(n log n) 更慢 |
| 数组交集 | O(1) 查存在 | 排序 O(n log n) + 双指针可行但代码长 |
| 快乐数 | O(1) 查状态重复 | 链表快慢指针也可（空间更优） |
| 两数之和 | O(1) 查补数 | 排序会打乱下标 |
| 四数相加II | O(n²) 分组查补数 | 四重循环 O(n⁴) 太慢 |
| 赎金信 | O(1) 查频率 | 排序 O(n log n) 更慢 |
| 三数之和 | — | **排序+双指针更优**（去重自然，空间 O(1)） |
| 四数之和 | — | **排序+双指针更优**（去重自然，空间 O(1)） |
