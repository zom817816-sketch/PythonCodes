# 链表算法总结

## 一、链表基础

链表是一种线性数据结构，每个节点包含**数据域**和**指针域**。与数组不同，链表在内存中不连续分布，通过指针连接各个节点。

### 链表的类型

| 类型     | 结构                           | 特点                           |
| -------- | ------------------------------ | ------------------------------ |
| 单链表   | `val` + `next`                 | 只能单向遍历                   |
| 双链表   | `val` + `next` + `prev`        | 双向遍历，插入/删除更灵活      |
| 循环链表 | 尾节点指向头节点               | 形成环，适合约瑟夫问题等       |

### 节点定义

```python
class ListNode:
    def __init__(self, val: int = 0, next: "ListNode | None" = None):
        self.val = val
        self.next = next
```

### 与数组的对比

| 维度     | 数组                 | 链表                     |
| -------- | -------------------- | ------------------------ |
| 内存分布 | 连续                 | 不连续（指针链接）       |
| 随机访问 | O(1)                 | O(n)                     |
| 插入删除 | O(n)（需移动元素）   | O(1)（修改指针即可）     |
| 大小     | 固定（需重新分配）   | 动态                     |
| 适用场景 | 频繁查询，少增删     | 频繁增删，少查询         |

## 三、核心技巧与通用模板

### 技巧一：虚拟头结点（Dummy Head）

**用途**：统一头节点和其他节点的操作，避免特判。

```python
# 通用模板
dummy = ListNode(0, head)
cur = dummy
while cur.next:
    # 统一处理，包括头节点
    ...
return dummy.next
```

**适用题目**：LC 203 移除链表元素、LC 24 两两交换、LC 19 删除倒数第N个节点、LC 707 设计链表。

### 技巧二：快慢指针

**用途**：找中点、找环、找倒数第N个、间距控制。

```python
# 模板1：找中点（slow 走到中间）
slow = fast = head
while fast and fast.next:
    slow = slow.next      # 慢指针走 1 步
    fast = fast.next.next  # 快指针走 2 步
# slow 在中点（或前半部分末尾）

# 模板2：判断有环
slow = fast = head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
    if slow is fast:
        break  # 有环，相遇

# 模板3：删除倒数第 N 个
# fast 先走 n+1 步，再同步前进
```

**适用题目**：LC 19 删除倒数第N个、LC 142 环形链表II、LC 876 链表的中间节点。

### 技巧三：递归

**用途**：反转链表、两两交换、回文判断等。代码简洁但空间 O(n)。

```python
# 递归模板
def recursive(head):
    # 基础情况
    if not head or not head.next:
        return head
    # 递归处理子问题
    result = recursive(head.next)
    # 后处理（回溯时操作）
    head.next.next = head
    head.next = None
    return result
```

**适用题目**：LC 206 反转链表、LC 24 两两交换、LC 203 移除链表元素。

### 技巧四：双指针路径等长

**用途**：相交链表，通过切换链表平衡路径长度差。

```python
pA, pB = headA, headB
while pA is not pB:
    pA = pA.next if pA else headB
    pB = pB.next if pB else headA
return pA
```

**适用题目**：LC 160 相交链表。

## 四、目录外常见题型

### 1. 回文链表（LC 234）

```python
def isPalindrome(head):
    # 快慢指针找中点
    slow = fast = head
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    # 反转后半部分
    prev = None
    while slow:
        temp = slow.next
        slow.next = prev
        prev = slow
        slow = temp
    # 比较前后两半
    left, right = head, prev
    while right:
        if left.val != right.val:
            return False
        left = left.next
        right = right.next
    return True
```

### 2. 合并两个有序链表（LC 21）

```python
def mergeTwoLists(list1, list2):
    dummy = ListNode(0)
    cur = dummy
    while list1 and list2:
        if list1.val <= list2.val:
            cur.next = list1
            list1 = list1.next
        else:
            cur.next = list2
            list2 = list2.next
        cur = cur.next
    cur.next = list1 if list1 else list2
    return dummy.next
```

### 3. 合并 K 个有序链表（LC 23）

```python
import heapq

def mergeKLists(lists):
    dummy = ListNode(0)
    cur = dummy
    heap = []
    for i, node in enumerate(lists):
        if node:
            heapq.heappush(heap, (node.val, i, node))
    while heap:
        val, i, node = heapq.heappop(heap)
        cur.next = node
        cur = cur.next
        if node.next:
            heapq.heappush(heap, (node.next.val, i, node.next))
    return dummy.next
```

### 4. 分隔链表（LC 86）

```python
def partition(head, x):
    small = ListNode(0)
    large = ListNode(0)
    s, l = small, large
    while head:
        if head.val < x:
            s.next = head
            s = s.next
        else:
            l.next = head
            l = l.next
        head = head.next
    l.next = None
    s.next = large.next
    return small.next
```

def middleNode(head):

### 6. K 个一组翻转链表（LC 25）

```python
def reverseKGroup(head, k):
    def reverse(head, tail):
        prev = tail.next
        cur = head
        while prev != tail:
            temp = cur.next
            cur.next = prev
            prev = cur
            cur = temp
        return tail, head

    dummy = ListNode(0, head)
    prev = dummy
    while head:
        tail = prev
        for _ in range(k):
            tail = tail.next
            if not tail:
                return dummy.next
        next_head = tail.next
        head, tail = reverse(head, tail)
        prev.next = head
        tail.next = next_head
        prev = tail
        head = next_head
    return dummy.next
```

### 7. 旋转链表（LC 61）

```python
def rotateRight(head, k):
    if not head or not head.next:
        return head
    # 计算长度并成环
    cur = head
    n = 1
    while cur.next:
        cur = cur.next
        n += 1
    cur.next = head  # 成环
    # 找到断点
    k = k % n
    for _ in range(n - k):
        cur = cur.next
    new_head = cur.next
    cur.next = None
    return new_head
```

### 8. 复制带随机指针的链表（LC 138）

```python
def copyRandomList(head):
    if not head:
        return None
    # 第一步：在每个节点后插入复制节点
    cur = head
    while cur:
        copy = Node(cur.val, cur.next, None)
        cur.next = copy
        cur = copy.next
    # 第二步：设置 random 指针
    cur = head
    while cur:
        if cur.random:
            cur.next.random = cur.random.next
        cur = cur.next.next
    # 第三步：分离两个链表
    cur = head
    new_head = head.next
    while cur:
        copy = cur.next
        cur.next = copy.next
        cur = cur.next
        if copy.next:
            copy.next = copy.next.next
    return new_head
```

### 9. 排序链表（LC 148）

```python
def sortList(head):
    if not head or not head.next:
        return head
    # 快慢指针找中点
    slow, fast = head, head.next
    while fast and fast.next:
        slow = slow.next
        fast = fast.next.next
    mid = slow.next
    slow.next = None
    # 递归排序两半
    left = sortList(head)
    right = sortList(mid)
    # 合并
    dummy = ListNode(0)
    cur = dummy
    while left and right:
        if left.val <= right.val:
            cur.next = left
            left = left.next
        else:
            cur.next = right
            right = right.next
        cur = cur.next
    cur.next = left if left else right
    return dummy.next
```

## 六、常见错误表

| 错误                         | 原因                               | 正确做法                                 |
| ---------------------------- | ---------------------------------- | ---------------------------------------- |
| 删除节点后 cur 前进          | 新的 cur.next 未检查               | 删除后 cur 不动                          |
| 指针修改顺序错               | 修改后丢失了后续节点               | 先保存所有需要的节点，再修改             |
| 快慢指针初始 slow == fast    | 起点重合不是相遇                   | 先各走一步再比较                         |
| 递归法忘记断开旧连接         | 链表尾部形成环                     | head.next = None                         |
| 相交链表用值比较             | 不同节点可能有相同值               | 用引用比较 `is`                          |
| 环形链表 fast 走 2 步不检查  | 无环时空指针异常                   | 检查 `fast and fast.next`                |
| 删除倒数第N个 fast 只走 n 步 | slow 停在待删节点而非前驱          | fast 走 n+1 步                           |
| 原始代码 `if slow = fast`    | `=` 是赋值不是比较                 | `if slow is fast`                        |
