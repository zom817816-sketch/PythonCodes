# 单调栈（Monotonic Stack）算法题总结

## 一、什么是单调栈

单调栈是一种特殊的 **栈** 数据结构，其内部元素保持 **单调递增** 或 **单调递减**。它不是一个新的算法，而是一个 **技巧 / 思维模式**——利用栈的 LIFO 特性，在线性时间内解决「找第一个更大/更小」「计算矩形面积」「去重保序」等问题。

| 分类 | 栈底 → 栈顶 | 适用场景 |
|------|------------|---------|
| 单调递增栈 | 从小到大 | 找右边/左边第一个**更小**的元素 |
| 单调递减栈 | 从大到小 | 找右边/左边第一个**更大**的元素 |

**复杂度**：时间 O(n)，空间 O(n)。每个元素最多入栈一次、出栈一次。

---

## 二、一眼识别单调栈题

遇到以下关键词或场景时，考虑单调栈：

1. **"下一个更大元素" / "下一个更小元素"** — 最典型的单调栈信号。
2. **"边界" / "最近" / "第一个"** — 找某根柱子两侧第一个满足条件的位置。
3. **"矩形面积" / "柱状图" / "雨水"** — 以每根柱子为高度，左右扩展找边界。
4. **"去重保持字典序最小"** — 弹走比当前元素大的栈顶（316 题）。
5. **"子数组最小值之和"** — 以每个最小值为中心，计算它在多少个子数组中充当最小值（贡献法）。
6. **"栈顶弹弹弹"** — 新元素来临时不断弹栈，直到满足某种单调性质。

**不适合单调栈**：需要随机访问、需要前 k 大、需要跨越多层的复杂比较。

---

## 三、记忆口诀

```
找更大 → 递减栈（小的被弹走，大的留下）
找更小 → 递增栈（大的被弹走，小的留下）
```

## 四、通用代码模板

### 模板 A：找「右边第一个更大」— 单调递减栈

```python
def find_next_greater(nums):
    n = len(nums)
    result = [-1] * n
    stack = []  # 存下标，对应值单调递减

    for i in range(n):
        # 当前元素比栈顶大 → 栈顶元素的"右边第一个更大"就是当前元素
        while stack and nums[i] > nums[stack[-1]]:
            top = stack.pop()
            result[top] = nums[i]   # 记录值
            # result[top] = i - top  # 或者记录距离
        stack.append(i)

    return result
```

### 模板 B：找「右边第一个更小」— 单调递增栈

```python
def find_next_smaller(nums):
    n = len(nums)
    result = [-1] * n
    stack = []  # 存下标，对应值单调递增

    for i in range(n):
        # 当前元素比栈顶小 → 栈顶元素的"右边第一个更小"就是当前元素
        while stack and nums[i] < nums[stack[-1]]:
            top = stack.pop()
            result[top] = nums[i]
        stack.append(i)

    return result
```

### 模板 C：哨兵版（一次遍历同时算左右边界）

```python
def monotonic_stack_with_sentinel(nums):
    # 右哨兵：末尾加 0（保证所有元素最终被弹栈）
    arr = nums + [0]
    # 左哨兵：栈初始化为 -1（简化栈空判断）
    stack = [-1]
    result = 0

    for i in range(len(arr)):
        while stack[-1] != -1 and arr[i] < arr[stack[-1]]:
            top = stack.pop()
            left = stack[-1]        # 弹出后的新栈顶 = 左边界
            width = i - left - 1    # i = 右边界
            area = arr[top] * width
            result = max(result, area)
        stack.append(i)

    return result
```

### 模板 D：循环数组 — 2n 遍历

```python
def next_greater_circular(nums):
    n = len(nums)
    result = [-1] * n
    stack = []  # 只存 0..n-1 的真实下标

    for i in range(2 * n):
        cur = nums[i % n]
        while stack and cur > nums[stack[-1]]:
            top = stack.pop()
            result[top] = cur
        # 只把前 n 个下标入栈，后半段是虚拟展开
        if i < n:
            stack.append(i)

    return result
```

### 题型 1：去重保持字典序最小 — LeetCode 316 / 1081

**题目**：给定字符串 `s`，移除所有重复字母，使结果字典序最小，且每个字母只出现一次。

**示例**：`s = "bcabc"` → `"abc"`，`s = "cbacdcbc"` → `"acdb"`

**核心思想**：

用单调递增栈（按字符字典序），每次入栈前：
1. 如果当前字符已经在栈中 → 跳过（避免重复）。
2. 如果栈顶字符比当前字符大，且后面还会再出现 → 弹出栈顶（为字典序让路）。

```python
def removeDuplicateLetters(s: str) -> str:
    last_index = {c: i for i, c in enumerate(s)}  # 每个字符最后出现的位置
    in_stack = set()
    stack = []

    for i, c in enumerate(s):
        if c in in_stack:
            continue
        # 栈顶字符比 c 大，且后面还会出现 → 弹走
        while stack and stack[-1] > c and last_index[stack[-1]] > i:
            in_stack.remove(stack.pop())
        stack.append(c)
        in_stack.add(c)

    return ''.join(stack)
```

**复杂度**：O(n) — 每个字符最多入栈出栈一次。

**关键洞察**：单调栈不只存数字，也可以存字符，比较的是字典序。`last_index` 字典是弹栈决策的辅助信息。

### 题型 2：子数组最小值之和 — LeetCode 907

**题目**：求数组 `arr` 的所有子数组的最小值之和。结果可能很大，返回对 `10^9 + 7` 取模的值。

**示例**：`arr = [3, 1, 2, 4]`，所有子数组共 10 个：

```
[3]→3, [3,1]→1, [3,1,2]→1, [3,1,2,4]→1
[1]→1, [1,2]→1, [1,2,4]→1
[2]→2, [2,4]→2
[4]→4
和 = 3+1+1+1 + 1+1+1 + 2+2 + 4 = 17
```

**核心思想（贡献法）**：

对每个位置 `i`，计算 `arr[i]` 在多少个子数组中充当**最小值**。设：
- `left[i]` = 左边**第一个严格小于** `arr[i]` 的下标（不存在则为 -1）
- `right[i]` = 右边**第一个小于等于** `arr[i]` 的下标（不存在则为 n）

则以 `arr[i]` 为最小值的子数组个数为：

```
count = (i - left[i]) × (right[i] - i)
```

贡献值 = `arr[i] × count`。

```python
def sumSubarrayMins(arr: list[int]) -> int:
    MOD = 10**9 + 7
    n = len(arr)

    # left[i]: 左边第一个严格小于 arr[i] 的下标，不存在则 -1
    left = [-1] * n
    stack = []
    for i in range(n):
        while stack and arr[stack[-1]] >= arr[i]:
            stack.pop()
        left[i] = stack[-1] if stack else -1
        stack.append(i)

    # right[i]: 右边第一个小于等于 arr[i] 的下标，不存在则 n
    right = [n] * n
    stack = []
    for i in range(n - 1, -1, -1):
        while stack and arr[stack[-1]] > arr[i]:
            stack.pop()
        right[i] = stack[-1] if stack else n
        stack.append(i)

    result = 0
    for i in range(n):
        count = (i - left[i]) * (right[i] - i)
        result = (result + arr[i] * count) % MOD

    return result
```

**为什么一边用 `<` 一边用 `<=`？**

因为数组中可能有重复值。如果两边都用严格小于，相等的两个元素会在边界处重叠计算，导致重复。一边用严格 `<`，另一边用 `<=`，可以让重复值的边界互不重叠。

### 题型 3：股票价格跨度 — LeetCode 901

**题目**：设计一个算法，收集某只股票每天的价格，并返回今天价格的"跨度"——今天之前（含今天）连续多少天的价格小于等于今天。

**示例**：

```
StockSpanner spanner = new StockSpanner();
spanner.next(100); // 今天之前没有 → 返回 1
spanner.next(80);  // 80 ≤ 100，跨度 = 1
spanner.next(60);  // 60 ≤ 80 ≤ 100，跨度 = 1
spanner.next(70);  // 70 ≤ 80，但 70 > 60 → 跨度 = 2 (今天和80那天)
spanner.next(60);  // 跨度 = 1
spanner.next(75);  // 75 ≥ 60, 75 ≥ 70, 75 < 80 → 跨度 = 4
```

**核心思想**：

维护一个单调递减栈，栈中存 `(价格, 跨度)` 二元组。当新价格来时：
1. 如果新价格 >= 栈顶价格，弹出栈顶，累加其跨度。
2. 弹完后将 `(新价格, 累加跨度 + 1)` 入栈。

```python
class StockSpanner:
    def __init__(self):
        self.stack = []  # [(price, span)]

    def next(self, price: int) -> int:
        span = 1
        while self.stack and self.stack[-1][0] <= price:
            span += self.stack.pop()[1]
        self.stack.append((price, span))
        return span
```

**关键点**：栈中直接存"跨度"而不是下标。弹栈时可以直接累加，不需要再计算距离。

### 题型 4：最终价格带折扣 — LeetCode 1475

**题目**：给定数组 `prices`，对每个 `prices[i]`，找到右边**第一个小于等于它**的 `prices[j]`（j > i），则 `prices[i]` 的实际价格 = `prices[i] - prices[j]`。如果不存在，不打折。

**示例**：`prices = [8, 4, 6, 2, 3]` → `[4, 2, 4, 2, 3]`

```
8 的折扣 = 8 - 4 = 4（右边第一个 ≤ 8 的是 4）
4 的折扣 = 4 - 2 = 2（右边第一个 ≤ 4 的是 2）
6 的折扣 = 6 - 2 = 4（右边第一个 ≤ 6 的是 2）
2 没有折扣 → 2
3 没有折扣 → 3
```

**核心思想**：右边第一个更小/更矮的变种。用单调递增栈。

```python
def finalPrices(prices: list[int]) -> list[int]:
    n = len(prices)
    result = prices[:]
    stack = []  # 存下标，对应值单调递增

    for i in range(n):
        # 当前价格比栈顶低 → 栈顶元素找到了"右边第一个 <= 它"的折扣
        while stack and prices[i] <= prices[stack[-1]]:
            top = stack.pop()
            result[top] -= prices[i]
        stack.append(i)

    return result
```

这道题是单调栈的"直接套模板"题，关键是识别出它属于"右边第一个更小"类型。

### 题型 5：能看到海景的建筑 — LeetCode 1762

**题目**：有一排建筑，第 i 栋的高度为 `heights[i]`。一栋建筑能看到海景的条件是：它右边所有建筑都比它矮。返回所有能看到海景的建筑下标（按升序）。

**示例**：`heights = [4, 2, 3, 1]` → `[0, 2, 3]`

```
下标 0 (h=4): 右边 2,3,1 都 < 4 → 能看到 ✓
下标 1 (h=2): 右边 3 > 2 → 被挡住 ✗
下标 2 (h=3): 右边 1 < 3 → 能看到 ✓
下标 3 (h=1): 最右边 → 能看到 ✓
```

**核心思想**：

逆序遍历，维护一个递减的"当前最大值"。如果 `heights[i]` 比当前最大值还大，说明它右边没有更高的建筑，能看到海景。

```python
def findBuildings(heights: list[int]) -> list[int]:
    result = []
    max_so_far = 0

    for i in range(len(heights) - 1, -1, -1):
        if heights[i] > max_so_far:
            result.append(i)
            max_so_far = heights[i]

    return result[::-1]  # 逆序得到升序
```

**和单调栈的关系**：虽然这道题用一次逆序遍历 + 一个变量就能解决，但本质上等价于"找右边第一个更大的元素"——如果不存在，就能看到海景。用单调栈写也是可以的：

```python
def findBuildings_stack(heights: list[int]) -> list[int]:
    n = len(heights)
    right_greater = [0] * n
    stack = []

    for i in range(n):
        while stack and heights[i] > heights[stack[-1]]:
            right_greater[stack.pop()] = 1
        stack.append(i)

    return [i for i in range(n) if right_greater[i] == 0]
```

两种写法都对，第一种更简洁。

### 题型 6：最大宽度坡 — LeetCode 962

**题目**：给定数组 `nums`，如果 `i < j` 且 `nums[i] <= nums[j]`，则称 `(i, j)` 是一个坡。坡的宽度 = `j - i`。返回最大宽度。

**示例**：`nums = [6, 0, 8, 2, 1, 5]` → `4`（i=1, j=5，宽度 4）

**核心思想**：

坡的条件是左边矮、右边高。要最大化 `j - i`，需要：
- 左边选尽可能小的值（`nums[i]` 尽可能小）
- 右边选尽可能大的值（`nums[j]` 尽可能大）

策略：
1. 建立一个 **递减栈**，存下标。遍历数组，只在 `nums[i] < nums[stack[-1]]` 时入栈（保持严格递减）。这样栈中存的是"从左到右高度单调递减的下标"。
2. 然后从右向左扫描，对每个 `j`，如果 `nums[j] >= nums[stack[-1]]`，说明栈顶下标 `i` 和 `j` 构成一个坡，记录宽度并弹栈（因为对这个 `i`，当前 `j` 已经是最优的了）。

```python
def maxWidthRamp(nums: list[int]) -> int:
    n = len(nums)
    stack = []  # 递减栈，存下标

    # 阶段 1：构建递减栈
    for i in range(n):
        if not stack or nums[i] < nums[stack[-1]]:
            stack.append(i)

    result = 0
    # 阶段 2：从右向左扫描
    for j in range(n - 1, -1, -1):
        while stack and nums[j] >= nums[stack[-1]]:
            result = max(result, j - stack.pop())

    return result
```

这道题是单调栈的"二段式"用法——先构建栈，再反向扫描弹栈。

### 题型 7：有效子数组计数 — LeetCode 2134 变种

**题目**：给定数组 `nums`，统计满足以下条件的子数组数量：子数组的最小值等于子数组的第一个元素（即第一个元素是子数组的最小值）。

**示例**：`nums = [1, 4, 2, 5, 3]`

```
[1] ✓, [1,4] ✓, [1,4,2] ✓, [1,4,2,5] ✓, [1,4,2,5,3] ✓
[4] ✓, [4,2] ✗ (min=2≠4), [4,2,5] ✗, [4,2,5,3] ✗
[2] ✓, [2,5] ✓, [2,5,3] ✓
[5] ✓, [5,3] ✗
[3] ✓
答案 = 5 + 1 + 3 + 1 + 1 = 11
```

**核心思想**：

对每个位置 `i`，找到右边第一个**严格小于** `nums[i]` 的位置 `j`。则以 `i` 开头、满足条件的子数组个数为 `j - i`。因为从 `i` 到 `j-1` 的所有子数组中，`nums[i]` 都是最小值。

```python
def countEffectiveSubarrays(nums: list[int]) -> int:
    n = len(nums)
    result = 0
    stack = []  # 单调递增栈，存下标

    for i in range(n):
        # 当前元素比栈顶小 → 栈顶找到了"右边第一个严格小于它"的位置
        while stack and nums[i] < nums[stack[-1]]:
            top = stack.pop()
            result += i - top
        stack.append(i)

    # 栈中剩余元素没有"右边更小"的，可以延伸到末尾
    while stack:
        top = stack.pop()
        result += n - top

    return result
```

### 题型 8：子数组最小乘积的最大值 — LeetCode 1856

**题目**：一个数组的"最小乘积"定义为该子数组的最小值 × 子数组元素和。返回所有子数组中最小乘积的最大值，对 `10^9 + 7` 取模。

**示例**：`nums = [1, 2, 3, 2]` → `14`（子数组 `[2,3,2]`，min=2，sum=7，2×7=14）

**核心思想**：

和题型 2 类似，用贡献法。对每个位置 `i`，当 `nums[i]` 作为子数组的最小值时：
- 找到左右边界（同题型 2）
- 子数组范围是 `(left, right)`，最大的子数组就是整个 `(left, right)` 区间
- 用 **前缀和** 快速算出区间和
- 贡献值 = `nums[i] × prefix[right] - prefix[left + 1]`

```python
def maxSumMinProduct(nums: list[int]) -> int:
    MOD = 10**9 + 7
    n = len(nums)

    # 前缀和
    prefix = [0] * (n + 1)
    for i in range(n):
        prefix[i + 1] = prefix[i] + nums[i]

    # left[i]: 左边第一个严格小于 nums[i] 的下标，不存在则 -1
    left = [-1] * n
    stack = []
    for i in range(n):
        while stack and nums[stack[-1]] >= nums[i]:
            stack.pop()
        left[i] = stack[-1] if stack else -1
        stack.append(i)

    # right[i]: 右边第一个小于等于 nums[i] 的下标，不存在则 n
    right = [n] * n
    stack = []
    for i in range(n - 1, -1, -1):
        while stack and nums[stack[-1]] > nums[i]:
            stack.pop()
        right[i] = stack[-1] if stack else n
        stack.append(i)

    result = 0
    for i in range(n):
        subarray_sum = prefix[right[i]] - prefix[left[i] + 1]
        result = max(result, nums[i] * subarray_sum)

    return result % MOD
```

**复杂度**：O(n) — 三次线性遍历（前缀和、左边界、右边界）+ 一次计算。

### 题型 9：小行星碰撞 — LeetCode 735

**题目**：给定整数数组 `asteroids`，每个数代表一颗小行星：绝对值表示大小，正/负表示方向（正=向右，负=向左）。相同方向的不碰撞，不同方向的如果会相遇就碰撞。碰撞后较小的消失，较大的继续；大小相同则都消失。模拟所有碰撞后返回最终状态。

**示例**：`asteroids = [5, 10, -5]` → `[5, 10]`，`asteroids = [10, 2, -5]` → `[10]`

**核心思想**：

用栈模拟碰撞过程。关键观察：
- 只有当栈顶向右（正数）且当前向左（负数）时，才会碰撞。
- 同向永远不碰撞，可以直接入栈。

```python
def asteroidCollision(asteroids: list[int]) -> list[int]:
    stack = []

    for cur in asteroids:
        exploded = False
        while stack and cur < 0 < stack[-1]:
            # 栈顶向右，当前向左 → 碰撞
            if stack[-1] < -cur:
                # 栈顶较小，弹走，继续和新栈顶比较
                stack.pop()
            elif stack[-1] == -cur:
                # 大小相同，都消失
                stack.pop()
                exploded = True
                break
            else:
                # 当前较小，当前消失
                exploded = True
                break
        if not exploded:
            stack.append(cur)

    return stack
```

**关键点**：这道题不是经典的"找边界"单调栈，而是用栈来模拟一个**碰撞消除过程**。弹栈的条件不再是单调性质被破坏，而是"方向相对"。这是单调栈思想的变体——用栈维护一个"尚未发生碰撞的有序序列"。

## 八、常见坑 & 易错点

| 坑 | 描述 | 正确做法 |
|----|------|---------|
| 搞反递增/递减 | 找更大却用了递增栈 | 记住：找更大→递减栈，找更小→递增栈 |
| 比较符号写错 | `>` vs `>=` 搞混 | 严格大于/小于才弹栈，边界条件看题目要求 |
| 宽度忘记减 1 | `right - left` 而非 `right - left - 1` | 左右边界柱子本身不计入宽度 |
| 忘记哨兵 | 遍历结束后栈中还剩元素 | 右哨兵 0 + 左哨兵 -1 一次解决 |
| 弹栈后旧栈顶 | `left = stack[-1]` 在 pop 之前取 | 先 pop 再取新的 stack[-1] |
| 重复值边界重叠 | 贡献法中重复值算两次 | 一边用 `<` 另一边用 `<=` |
| 循环数组只遍历 n | 没遍历 2n 次 | `for i in range(2*n)`，且只入栈 `i < n` |
| 存值 vs 存下标 | 需要距离时存了值 | 需要计算距离/面积时必须存下标 |
| 修改原数组 | `heights.append(0)` | 用 `heights + [0]` 创建新数组 |
| while 写成 if | 一次弹多个只弹了一个 | 弹栈条件必须是 `while` |
